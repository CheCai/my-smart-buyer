# my-smart-buyer

个人专属「购物决策」Skill —— 在每次买买买之前，用一套固定流程帮你做清醒、可查证、避坑的选型判断。

## 它解决什么问题

大多数人买东西凭感觉、被促销牵着走。这个 Skill 把「买不买、买哪个、值不值、怎么避坑」拆成一套可复用的决策流水线，专治冲动消费和隐形坑。

## 核心流程（每次购物走一遍）

1. **前提核查**：先检查问题里的错误前提 / 逻辑跳跃 / 信息缺失，不迎合
2. **断舍离筛查**：这东西你真的需要吗？是不是新增负担？
3. **保值 / 残值评估**：用多久、能不能卖、贬值快不快
4. **选型对比**：安全品类必核国标 / 3C / 欧标美标对照，未标标准号直接淘汰
5. **技术拆解**：观察 → 类比 → 测试 → 商业化，每次研究记 1 个可改进点
6. **隐性成本**：价格有效期、实际权益口径、合约期 / 注销违约金、能否官方查证
7. **对照表 + 精华总结**：最终输出可快速回顾的结论

## 使用方法

在支持 Skill 的对话环境中，把本目录作为 Skill 安装到用户技能根目录，之后提到「要不要买 / 买哪个 / 值不值 / 怎么避坑」等需求时自动触发。

## 特点

- 重视可查证、眼见为实：所有标准、参数、权益都以官方来源为准
- 主动提醒隐性成本与认知偏差，不为了让用户舒服而附和
- 追求质量而非数量：符合「断舍离」的个人价值观
